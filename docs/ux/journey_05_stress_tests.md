# Tenor — Jornada 5: Stress tests (versão massa)

> **Objetivo**: deixar a massa ensaiar "e se a vida mudar?" sem alarmismo — planejamento, não pânico.
> **Princípio guia**: stress test para a massa é **tranquilidade antecipada** ("se acontecer X, eu sei o que fazer"), não otimização de risco.
>
> Como os cenários (jornada 2), esta jornada é **secundária** no produto de massa: ofertada, nunca imposta.

---

## Modelo mental do usuário (massa)

> "E se eu perder o emprego — quanto tempo eu aguento pagar? E se minha renda subir, o que faço com a sobra? Se a Selic cair, vale trocar de banco?"

São medos e dúvidas concretas da vida real, não exercícios financeiros abstratos.

---

## Princípios duros

1. **Ensaio sem compromisso.** Nada mexe no contrato.
2. **Sem alarmismo.** "Perda de emprego" é tratado com cuidado, focado em ação, não em medo.
3. **Sempre termina em ação concreta** ("reforçar reserva", "diversificar", "decidir depois").
4. **Três testes predefinidos** cobrem 90% da massa; o resto é custom (nicho).

## Tela 5.2 — "Perdi o emprego" (cuidado, sem pânico)

```
┌──────────────────────────────────────────────────────────┐
│  ←  Se você perder a renda                               │
│                                                          │
│  Quanto você tem guardado pra emergência?                │
│  [ R$            ]   (ou "não tenho")                    │
│                                                          │
│  Seus gastos fixos por mês (fora a parcela)?             │
│  [ R$            ]                                        │
│                                                          │
│  ┌────────────────────────────────────────────┐         │
│  │  Com R$ 18.000 guardados e a parcela de       │       │
│  │  R$ 1.247, você consegue pagar por cerca de   │       │
│  │  ~7 meses só com a reserva.                    │       │
│  │                                                │       │
│  │  Antes de chegar lá, o banco costuma ter       │       │
│  │  opções: pausa de parcela ("carência") ou      │       │
│  │  renegociação. Procurar ANTES de atrasar       │       │
│  │  muda tudo.                                     │       │
│  └────────────────────────────────────────────┘         │
│                                                          │
│  [ Quero reforçar minha reserva ]                        │
│  [ Ver como funciona a carência ]                        │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### Decisões
- **Tom de cuidado.** Foca em "o que fazer" e em recursos reais (carência, renegociação), não no medo.
- **Não dá conselho jurídico**; orienta procurar o banco antes de atrasar.

## Tela 5.3 — "Minha renda aumentou" (o teste que você pediu)

```
┌──────────────────────────────────────────────────────────┐
│  ←  Sua renda aumentou. E agora?                         │
│                                                          │
│  Quanto sobra a mais por mês?   [ R$            ]        │
│                                                          │
│  Três caminhos — sem resposta única:                     │
│                                                          │
│  ⦿ Adiantar o financiamento                              │
│     R$ 300/mês → termina ~6 anos antes,                  │
│     economiza R$ 71.000 em juros                         │
│                                                          │
│  ⦾ Guardar / diversificar                                │
│     Mantém liquidez pra outros planos                    │
│                                                          │
│  ⦾ Reforçar a reserva primeiro                           │
│     Se a sua ainda não cobre 6 meses                     │
│                                                          │
│  ⓘ Eu mostro a conta de cada um. A decisão é sua.        │
│                                                          │
│  [ Quero adiantar ]  [ Comparar os três ]                │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### Decisões
- **Três caminhos, não uma recomendação única.** Adiantar é uma opção entre três.
- **Considera reserva** antes de empurrar o financiamento.

```
┌──────────────────────────────────────────────────────────┐
│  ←  Vale trocar de banco (portabilidade)?                │
│                                                          │

│                                                          │
│  ┌────────────────────────────────────────────┐         │
│  │  Trocar economizaria ~R$ 38.000 ao longo do  │        │
│  │  contrato.                                    │        │
│  │  Custos da troca (cartório, avaliação):       │        │
│  │  ~R$ 3.500 (estimativa para sua cidade).      │        │
│  │  Compensa em ~14 meses.                        │        │
│  └────────────────────────────────────────────┘         │
│                                                          │
│  ⓘ Estimativa. Não indico banco e não ganho comissão.    │
│     Os custos variam por cartório e cidade.              │
│                                                          │
│  [ Gerar resumo pra levar ao banco ]                     │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### Decisões
- **Inclui os custos de troca** — honestidade que o lead de portabilidade esconde.
- **Neutralidade reafirmada.**

---

## Casos de borda

### Sem reserva nenhuma
```
Você marcou "não tenho reserva". Antes de qualquer
adiantamento ou troca, o passo mais importante é
montar um colchão de emergência. Quer simular isso?
```

### Pergunta sensível demais
```
Stress tests são ensaios, não previsões. A vida real
tem mais variáveis. Use isso pra se preparar, não pra
se assustar.
```

## Diferenças nicho × massa

| | Nicho (Quitador) | Massa (Confuso) |
|---|---|---|
| Testes | Custom, múltiplas variáveis | 3 predefinidos + custom |
| Enquadramento | Otimização de risco | Planejamento tranquilo |
| "Perda de emprego" | Variável de stress | Tratado com cuidado e recursos reais |

## Métricas que importam

| Métrica | Meta |
|---|---|
| Usuários que rodam ≥ 1 stress test | acompanhar |
| Conclusão do teste "perda de emprego" sem abandono | sinal de tom adequado |
| Conversão "renda aumentou" → ação | acompanhar |
