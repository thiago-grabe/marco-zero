# Tenor — Jornada 2: Cenários (versão massa)

> **Objetivo**: deixar a massa experimentar "e se eu adiantar um pouco?" sem medo, sem jargão e sem pressupor capital sobrando.
> **Princípio guia**: para a massa, cenário não é otimização — é **uma vitória pequena e concreta**. "R$ 53 a mais cortam 1 ano" engaja mais do que "maximize o retorno marginal".
>
> No produto de massa, esta jornada **recua para segundo plano**: não é porta de entrada, é o que o usuário descobre depois. Os cenários comparados completos continuam existindo para o nicho (perfil "Quitador").

---

## Modelo mental do usuário (massa)

> "Será que vale a pena pagar um pouquinho a mais? Quanto isso muda? Mas será que eu deveria guardar esse dinheiro em vez de jogar no financiamento?"

A dúvida da massa é tímida e acessível: não é "amortizo R$ 80k", é "arredondo a parcela". E sempre vem com culpa/insegurança sobre estar fazendo a coisa certa com pouco dinheiro.

---

## Princípios duros

1. **Adiantamento pequeno como padrão.** Slider em reais baixos, não campo de "amortização extra".
2. **Vitória traduzida em tempo, não só em juros.** "Termina X meses antes" pesa mais que "economiza R$ Y".
3. **Sempre checa reserva de emergência** antes de empurrar adiantamento. Tranquilidade > otimização.
4. **Comparar com "guardar o dinheiro"** é a comparação honesta da massa (não "investir em ações").
5. **Sem mexer no contrato.** Cenário é ensaio; nada é registrado até o usuário declarar.

## Tela 2.1 — "E se eu adiantar um pouco?"

```
┌──────────────────────────────────────────────────────────┐
│  ←  E se eu adiantar um pouco?                           │
│                                                          │
│  Quanto você consegue por mês, além da parcela?          │
│                                                          │
│     R$ 0  ───────●──────────────────  R$ 500            │
│                R$ 53                                     │
│                                                          │
│  ┌────────────────────────────────────────────┐         │
│  │  Com R$ 53 a mais por mês:                   │        │
│  │                                              │        │
│  │   Você termina em   Jan/2041                 │        │
│  │   (1 ano e 2 meses antes)                    │        │
│  │                                              │        │
│  │   Economiza         R$ 11.380 em juros       │        │
│  └────────────────────────────────────────────┘         │
│                                                          │
│  ⓘ Isso só faz sentido se você já tem uma reserva de     │
│     emergência. Quer que eu te ajude a checar?           │
│                                                          │
│  [ Quero adiantar ]  [ Comparar com guardar o dinheiro ] │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### Decisões
- **Slider em reais pequenos** (R$ 0–500), com o valor escolhido em destaque.
- **Resultado em tempo primeiro, juros depois.** O efeito psicológico do tempo é mais forte.
- **Checagem de reserva** aparece antes do CTA de adiantar.

## Tela 2.2 — Adiantar agora vs todo mês

```
┌──────────────────────────────────────────────────────────┐
│  ←  Como você quer adiantar?                             │
│                                                          │
│  ⦿ Um pouco todo mês                                     │
│     Ex.: R$ 53 a mais na parcela                         │
│     → termina Jan/2041, economiza R$ 11.380              │
│                                                          │
│  ⦾ Um valor de uma vez                                   │
│     Ex.: o 13º, uma reserva, FGTS                        │
│     [ R$            ]                                     │
│                                                          │
│  ── O que isso faz com a dívida ───────────────          │
│  ⦿ Encurtar o prazo (acabar antes)                       │
│  ⦾ Diminuir a parcela (aliviar o mês)                    │
│                                                          │
│  [ Ver o resultado ]                                     │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### Decisões
- **Duas formas de adiantar** em linguagem de massa (todo mês vs de uma vez).
- **"Encurtar prazo" vs "diminuir parcela"** explicado pelo efeito, não pelo nome técnico.
- **FGTS citado como exemplo concreto** — é o "dinheiro de uma vez" mais comum da massa.

## Tela 2.3 — Comparar com guardar o dinheiro

```
┌──────────────────────────────────────────────────────────┐
│  ←  Adiantar ou guardar?                                 │
│                                                          │
│  Comparando R$ 53/mês por 5 anos:                        │
│                                                          │
│  Adiantar no financiamento                               │
│   • Economia garantida em juros: R$ 11.380               │
│   • É "retorno certo": a taxa do seu contrato            │
│                                                          │
│  Guardar numa renda fixa simples                         │
│   • Rende ~X% ao ano (você escolhe a taxa)               │
│   • Tem liquidez: dá pra usar numa emergência            │
│                                                          │
│  ⓘ Regra prática: se a taxa do seu financiamento for     │
│     maior que a da aplicação, adiantar costuma ganhar —  │
│     mas guardar dá segurança. Não indico produto nem     │
│     instituição.                                         │
│                                                          │
│  [ Simular com outra taxa ]                              │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### Decisões
- **Comparação honesta e genérica** — renda fixa simples, sem nomear instituição (recusa de conselho de investimento).
- **Liquidez é citada como valor** — coerente com "tranquilidade", não só matemática.

## Tela 2.4 — Cenários salvos (leve)

```
┌──────────────────────────────────────────────────────────┐
│  ←  Meus ensaios                                         │
│                                                          │
│  Você salvou:                                            │
│                                                          │
│  💡 R$ 53/mês — termina Jan/2041                         │
│     [ Ver ]  [ Apagar ]                                  │
│                                                          │
│  💡 FGTS R$ 18k em 2027 — termina Set/2040               │
│     [ Ver ]  [ Apagar ]                                  │
│                                                          │
│  ⓘ Ensaios não mexem no seu contrato. São só pra você    │
│     se planejar.                                         │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### Decisões
- **"Ensaios", não "cenários".** A massa entende ensaio como "experimentar sem compromisso".
- **Limite baixo no plano grátis** (ex.: 2 ensaios); ilimitado nos pagos.

## Casos de borda

### Usuário sem reserva
```
Antes de adiantar, vale ter um colchão pra
imprevistos. Adiantar é ótimo, mas dinheiro preso
no imóvel não paga uma emergência. Quer simular
guardando 3 meses de despesa primeiro?
```

### Adiantamento que mal muda nada
```
R$ 10/mês adianta o fim em ~2 meses ao longo de
15 anos. Faz pouca diferença. Se der, R$ 50+ já
muda bem mais o jogo — mas só se couber no seu mês.
```

## Diferenças nicho × massa

| | Nicho (Quitador) | Massa (Confuso) |
|---|---|---|
| Entrada | Campo de amortização extra (R$ k) | Slider de R$ 0–500 |
| Comparação | Amortizar vs investir (ativos) | Adiantar vs guardar (renda fixa simples) |
| Métrica destacada | Juros economizados | Tempo cortado |
| Posição no produto | Feature central | Segundo plano, descoberta depois |

---

## Métricas que importam

| Métrica | Meta |
|---|---|
| Usuários que rodam ao menos 1 ensaio | > 25% dos ativos |
| Conversão ensaio → adiantamento declarado | acompanhar |
| Uso da checagem de reserva | sinal de saúde do produto |
